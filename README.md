# bobrovylog — сайт Фанпарк «Бобровый лог»

Боевой сайт: https://bobrovylog.ru
Репозиторий: https://github.com/Onexiw/bobrovylog (приватный)
CMS: 1С-Битрикс («Bitrix Site Manager»), PHP + nginx.
Задача: подключить весь код сайта к локальному проекту, чтобы вносить правки, исправления и модернизацию безопасно и с историей изменений.

## Структура

```
bobrovylog/
├── README.md          ← этот файл
├── .gitignore
├── site/              ← локальная копия кода сайта (появится после выгрузки с хостинга)
├── deploy/            ← скрипты выгрузки/загрузки
├── docs/              ← аудит, план работ, журнал изменений
└── _local/            ← доступы и черновики (в git не попадает)
```

## Правила работы

1. Правки делаем локально в `site/`, а не в админке Bitrix, — так есть история и возможность отката.
2. Перед любой выгрузкой на прод: бэкап затрагиваемых файлов + `php -l` для изменённых файлов.
3. Секреты не коммитим: они лежат в `_local/`.
4. Каждое изменение — запись в `docs/журнал-изменений.md` (что, где, зачем, когда).
