# Мониторинг продакшена

Настроен 11.11.2026 на сервере.

## Что проверяется (каждые 5 минут)

Скрипт `/usr/local/bin/dsh-health.sh` (в репозитории: `deploy/monitor-health.sh`):

1. **HTTP-коды** ключевых страниц через локальный nginx с `Host: bobrovylog.ru`:
   `/`, `/raspisanie/`, `/services/`, `/news/`, `/about/`, `/bitrix/admin/` — ожидается 200.
2. **Диск** — ALERT при заполнении ≥ 85%.
3. **Память** — ALERT, если доступно < 200 МБ.
4. **TLS-сертификат** — ALERT, если до истечения < 30 дней (сейчас до 19.01.2027 ≈ 68 дней).
5. **Сервисы**: nginx, php83-php-fpm, mysqld, memcached, crond — должны быть active.
6. **5xx** в nginx access log с момента прошлого запуска — ALERT при > 5.

Результат — одна строка в `/var/log/dsh-health.log`:

```
2026-11-11T19:55:16+0700 status=OK http: /=200 /raspisanie/=200 ... disk=71% mem_avail=1708MB cert_days=68 5xx_since_last=0 services:[nginx=active ...]
```

## Установка / обновление

```bash
scp deploy/monitor-health.sh root@62.213.48.144:/usr/local/bin/dsh-health.sh
ssh root@62.213.48.144 "chmod 755 /usr/local/bin/dsh-health.sh && /usr/local/bin/dsh-health.sh"
```

Cron: `/etc/cron.d/dsh-health` (каждые 5 минут, от root).
Ротация: `/etc/logrotate.d/dsh-health` (еженедельно, 8 архивов).

## Как смотреть

```bash
ssh root@62.213.48.144 "tail -20 /var/log/dsh-health.log"
ssh root@62.213.48.144 "grep -c status=ALERT /var/log/dsh-health.log"   # сколько алертов
```

При первом запуске был ложный ALERT из-за подсчёта истории 5xx (включая инцидент 15:49–16:00);
смещение инициализировано текущим размером лога — дальше считаются только новые ошибки.
