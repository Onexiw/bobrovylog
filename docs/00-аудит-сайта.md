# Аудит сайта bobrovylog.ru

Дата: 11.11.2026. Выполнено без доступа к коду — по внешним и локальным данным.

## 1. Что за сайт

- Адрес: https://bobrovylog.ru — «Фанпарк Бобровый лог» (Красноярск).
- CMS: **1С-Битрикс**, заголовок `X-Powered-CMS: Bitrix Site Manager (b59d928c2912d6f22969c17025b1f0b4)`.
- Веб-сервер: **nginx**, PHP-сессии (`PHPSESSID`), заголовки `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`.

## 2. Структура кода (по публичным признакам)

- Кастомный шаблон сайта: `/local/templates/bobrovy_log_multilang/` — **мультиязычный** (шифр шаблона `s1`, кэш в `/bitrix/cache/css|js/s1/bobrovy_log_multilang/`).
- Кастомный компонент расписания: `/bitrix/components/mibok/rasp.timetable.list/` (ajax-точка `ajax.php`, скрытое поле `TIMETABLE_AJAX` в разметке). Т.е. в проекте есть **чужой коммерческий/самописный компонент** `mibok` — его нельзя перезаписывать обновлениями.
- Ядро Битрикса в `/bitrix/`, кэш в `/bitrix/cache/`, картинки и файлы в `/upload/iblock/...`.
- JS: Битриксовый `core.min.js`, встроенный jQuery 1.12.4.
- Внешние интеграции: `sale.moipass.ru` (скрипт), виджет погоды `meteoservice.ru`.

## 3. Инфраструктура и домен

- IP сайта: **62.213.48.144** — сеть ISKRANET (RIPE), Красноярск, оператор «Спутниковая связь»/data-pool.
- NS домена: `ispns1.data-pool.ru`, `ispns2.data-pool.ru` — **домен уже перенесён** на локальный хостинг data-pool.
- MX: `mail.bobrovylog.ru` → 62.213.61.77; SPF `v=spf1 ip4:62.213.61.77 a mx ~all`.
- История: экспорт зоны от 27.10.2026 (файлы `bobrovylog.ru.zone*.txt` в Downloads) ещё описывает SpaceWeb (`www → 77.222.40.251`, NS `ns1–ns4.spaceweb.*`). Значит, сайт **недавно переехал со SpaceWeb на data-pool** — это надо учитывать: возможны остатки старых настроек и старые бэкапы.
- **Проблема:** `www.bobrovylog.ru` сейчас **не резолвится** (нет A/CNAME). Сайт открывается только без `www` — это стоит исправить (склейка зеркал, SEO).

## 4. TLS / безопасность

- HTTPS работает: **TLS 1.3**, сертификат **GlobalSign** `*.bobrovylog.ru` + `bobrovylog.ru`, действителен до **19.01.2027**.
- Порт 22 (SSH) открыт, баннер **OpenSSH_7.4** — типичная ОС для хостинга уровня CentOS 7. Штатный путь к коду — SSH/SFTP.
- Порт 21 (FTP) закрыт; MySQL (3306) снаружи закрыт.
- Нет заголовка HSTS. Не критично, но в список модернизации.

- `Downloads/bobrovylog.ru.zone*.txt` — экспорты DNS-зоны.

## 6. Чего не хватает для работы «по-взрослому»

1. **Доступа к коду**: локальной копии нет, git нет, полного бэкапа сайта нет.
2. **SSH/SFTP-доступа** к хостингу (или панели data-pool) — без него «весь код» не забрать.
3. **Доступа в админку Битрикса** (для настроек, компонентов, очистки кэша, работы с инфоблоками).
4. **Тестового контура**: правки сразу на проде рискованны.
5. **Локальных инструментов**: на машине нет git, PHP CLI, Node — для проверки синтаксиса и версионирования их нужно поставить (winget доступен).
