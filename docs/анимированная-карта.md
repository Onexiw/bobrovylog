# Интерактивная карта фанпарка

Страница `site/karta/animation/index.php` доступна по адресу `/karta/animation/` и использует общую шапку, логотип, подвал и шрифты сайта из шаблона Битрикс. Пункт меню «Карта фанпарка» ведёт на неё. Ссылка «Классическая карта» возвращает к прежней странице с сезонными картами Mapplic.

## Состав

- `site/karta/animation/index.php` — адаптивная карта, интерактивные точки, фильтры и приближение без декоративных фоновых эффектов.
- `site/karta/animation/assets/map-base.jpg` — оптимизированный фрагмент предоставленного баннера с зимней картой.
- `site/.top.menu.php` и `site/.top_ru.menu.php` — путь пункта карты в меню.

## Встраивание в другую страницу

```html
<iframe
  src="/karta/animation/?embed=1"
  title="Интерактивная зимняя карта фанпарка"
  style="display:block;width:100%;height:780px;border:0"
  loading="lazy"
></iframe>
```

Точки и описания демонстрационные. Модель не получает текущие статусы склонов, погоду или расписания подъёмников. Перед публикацией нужно сверить названия и координаты объектов с актуальной картой.

Папка `site/karta/` обычно исключена из Git, поэтому в `.gitignore` добавлены исключения только для файлов этой модели. Остальные файлы и генерируемые данные в `site/karta/` остаются исключёнными.
